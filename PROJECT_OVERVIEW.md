## 🚀 Co dělat dál?

### Rychlý postup (5 minut):

1. **Stáhni tuto složku** na svůj počítač
2. **Spusť deployment script:**
   - Windows: Dvojklik na `deploy.bat`
   - Linux/Mac: Spusť `./deploy.sh` v terminálu
3. **Aktivuj GitHub Pages:**
   - Jdi na Settings → Pages
   - Vyber "GitHub Actions"
4. **Přidej obrázky:**
   - Zkopíruj složku `obrazky/` z původního projektu
   - `git add obrazky/ && git commit -m "Add images" && git push`
5. **Hotovo!** Web je na: https://r4-d3k.github.io/SoulKnightWiki/

## 💡 Tipy

### Aktualizace webu:
```bash
git add .
git commit -m "Update: popis změny"
git push
```
Web se automaticky aktualizuje za 1-2 minuty!

### Sledování nasazení:
- Jdi na Actions tab v GitHub repository
- Sleduj zelené/červené fajfky
- Klikni na workflow pro detail

### Testování responsivity:
- Desktop: Otevři web v prohlížeči
- Mobile: F12 → Device toolbar (ikona telefonu)
- Nebo testuj na skutečném telefonu

## 🆘 Pomoc

Pokud něco nefunguje:

1. **Přečti si:**
   - QUICK_START.md - rychlé řešení
   - DEPLOYMENT_GUIDE.md - detailní návod
   - README.md - kompletní dokumentace

2. **Zkontroluj:**
   - Je repository PUBLIC?
   - Běží GitHub Actions?
   - Je Pages aktivován?

3. **Časté problémy:**
   - 404 error → Zkontroluj Pages settings
   - Obrázky nefungují → Přidej složku obrazky/
   - Push selhává → Zkontroluj Git credentials
