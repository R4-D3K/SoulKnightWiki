## 🚀 Jak přidat obrázky / How to add images

### Krok 1: Zkopíruj složky
Zkopíruj všechny podsložky a soubory z původního projektu do této složky.

### Krok 2: Přidej do Gitu
```bash
cd /cesta/k/SoulKnightWiki
git add obrazky/
git commit -m "Add all images"
git push
```

### Krok 3: Počkej na nasazení
GitHub Pages se automaticky aktualizuje za 1-2 minuty.
